## The entry

`main.py` writes a single original roast line about the entrant's own fridge to `/output/entry.txt` — the ice maker that groans like it's deadlifting, drops two cubes, and then files for workers' comp. Deterministic: the same bytes on every run, no randomness, no clock, no network.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
